# ✦ MI MANHWA STUDIO

App personal para crear manhwas: biblia y universo, capítulos con IA, editor de manhwa con capas,
animación hecha con código, editor de video para redes, lector en audio y conexión con Claude Code.

- **App publicada:** https://aeterion77-crypto.github.io/mi-manhwa-studio/
- `index.html` + íconos + `sw.js` + `manifest.webmanifest` = la app instalable (PWA).
- `puente/` = puente local para conectar Claude Code (doble clic en *INICIAR PUENTE*).
- `fuente/` = código fuente (`src/`) y `build.sh` que arma `index.html`; `supabase-funcion/` = función segura de Supabase.

Los datos viven en Supabase con acceso solo para la cuenta dueña. Este repositorio no contiene llaves secretas.
